# ADR-0001: Скомпилированный CLI — единственный тестовый шов

## Status

Accepted

## Context

Харнес поставляется как CLI: всё, что о репозитории можно узнать, читается из его вывода и
кода возврата. Тесты могли бы обращаться к типам внутри сборки — через `InternalsVisibleTo`
или сделав их `public`. Тогда контрактом становится внутренняя структура (`Checks/`,
`Engine/`, `Git/`), а не наблюдаемое поведение, и она перестаёт меняться свободно.

## Decision

`tests/Harness.Tests` гоняет скомпилированный исполняемый файл и проверяет его stdout и код
возврата. Internal-типы не становятся `public` только ради тестируемости.

## Consequences

### Positive

- Тестируется то же, что видит пользователь: вывод и код возврата.
- Внутреннюю структуру можно менять, не переписывая тесты.

### Negative / Risks

- Тесты требуют публикации исполняемого файла и потому медленнее внутримодульных.
- Поведение, ненаблюдаемое через CLI, не покрывается тестами.
