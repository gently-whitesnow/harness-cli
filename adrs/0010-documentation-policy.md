# ADR-0010: Документационная политика

## Status

Accepted

## Context

Пользователь разрешил текстовые инструкции только как навигацию, а не как источник истины:
переиспользуемое правило должно стать гейтом. Долговременное знание разделено между кодом и
тестами (что система делает сейчас), ADR (почему выбрано долгосрочное решение) и историей
task/MR/commit. Постоянную feature specification пользователь исключил из модели.

В дизайн-сессии отдельно подтверждены четыре решения: разрешить короткий root `README.md`,
держать ADR непосредственно в root `adrs/`, ограничить агентскую навигацию 150 строками и
сделать `AGENTS.md`/`CLAUDE.md` не копиями, а прямыми symlink одного `ROOT.md`. Временная
build spec и tickets жили под `.scratch` и были удалены после реализации; стандартный setup,
создающий `CONTEXT.md` и `docs/agents/*.md`, сознательно не использовался как постоянная
структура этого репозитория.

## Decision

`ROOT.md` — единственный источник агентской навигации, не более 150 физических строк.
`AGENTS.md` и `CLAUDE.md` — прямые относительные симлинки на него: цепочка ссылок, битая
ссылка, абсолютная ссылка и обычный файл различимы, потому что ссылки читаются из индекса
Git. `README.md` — краткий обзор. Долговременные решения живут в `adrs/`. Прочий tracked
Markdown даёт blocking-находку. Репозиторий может осознанно смягчить всю проверку через
`policy` или принять конкретный путь через именованный `suppress` с обязательной причиной.

Разделение труда между `ROOT.md` и `adrs/`: `ROOT.md` несёт действующее правило в одну
строку со ссылкой на ADR, ADR несёт контекст, решение и последствия. Правило нужно на
каждом шаге и стоит контекста каждый раз, обоснование — один раз, когда правило собираются
изменить.

## Consequences

### Positive

- В текущем Git index `AGENTS.md` и `CLAUDE.md` имеют mode `120000` и одну цель `ROOT.md`;
  навигация действительно хранится один раз.
- Текущий tracked Markdown состоит из `README.md`, `ROOT.md`, двух symlink и `adrs/`; после
  переноса долговременных решений отдельный каталог `docs/` удалён.
- Длина `ROOT.md` проверяется исполняемым гейтом, а не договорённостью.

### Negative / Risks

- Политика намеренно opinionated и не описывает все экосистемы: репозиторий с ADR и agent
  skills в других tracked Markdown locations должен настроить `policy` или `suppress`.
- Симлинк читают не все инструменты. services-platform держит `AGENTS.md` и `CLAUDE.md`
  файлами-стабами со ссылкой на `ROOT.md` и получает от `docs.policy` violation.
- Windows portability симлинков в v0 не решается; первые поддерживаемые среды — macOS и
  Linux.
