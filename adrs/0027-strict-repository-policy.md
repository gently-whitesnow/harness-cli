# ADR-0027: Репозиторий может сделать advisory-находки строгим локальным контрактом

## Status

Accepted.

## Context

Проверка знает, насколько уверенно её формула доказывает дефект, поэтому лексические метрики
по умолчанию остаются advisory. Но конкретный репозиторий может принять более узкое правило:
например, ни один измеренный метод не превышает выбранную им границу. Обычный `required`
этого не выражает: он требует запуск и блокирует доказанные нарушения, сохраняя исходную
severity остальных находок.

Подмена смысла `required` сделала бы существующие репозитории красными после обновления
бинаря. Настройка внутри каждой метрики, напротив, размножила бы один и тот же механизм и не
дала бы строго применять проверки без числовых settings.

## Decision

`policy` принимает явное значение `strict`. После применения именованных `suppress` оно
повышает каждую оставшуюся находку выбранной проверки до `Blocking` и завершает проверку как
`Failed`. Поэтому suppress продолжает принимать конкретное известное исключение, а strict
блокирует любое новое.

`required` остаётся значением по умолчанию и сохраняет severity, назначенную проверкой.
`advisory` понижает blocking-нарушения, `off` не запускает проверку. Если рамка невалидна,
никакой focused selector не запускает проверки на defaults: весь прогон остаётся
`Incomplete` на `harness.config`.

Strict утверждает соблюдение локально выбранной измеримой границы, а не превращает формулу в
универсальное доказательство архитектурного дефекта. Поэтому тексты находок и `explain`
продолжают называть точное измерение и его ограничения.

## Consequences

- Репозиторий может сделать advisory-анализ регрессионным CI-гейтом без изменения дефолта
  для остальных потребителей.
- Новая находка блокирует прогон; известное исключение обязано иметь адрес и причину.
- Владелец должен сначала проверить false positives и выбрать осмысленные settings: strict
  намеренно принимает риск локальной policy поверх эвристики.
- `required` и `strict` различаются: первое доверяет severity проверки, второе усиливает её.
